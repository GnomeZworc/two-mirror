Démarrage
=========

Le parcours court : un hyperviseur, un VPC, un subnet, une VM qui démarre. Tout reste sur le
même nœud — c'est suffisant pour valider une installation et pour découvrir le modèle, pas pour
faire fonctionner un parc.

Pour un cluster, poursuivre avec :doc:`/deploiement/index`.
