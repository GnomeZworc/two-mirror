Versions#

Chaque version porte un nom de code dérivé du rang de sa publication : anges et démons alternés.

  • Michael

Noms de version#

Anges et démons alternés, tirés de traditions du domaine public : archanges, Veilleurs du Livre d’Hénoch et anges du Shem HaMephorash pour les premiers, Ars Goetia dans son ordre canonique pour les seconds.

Le nom se déduit du rang, pas du numéro de version : la n-ième release prend le n-ième nom. La fonction de release n’a donc rien à choisir, et aucun nom ne peut être réutilisé.

Renseignement des colonnes#

Version et Date sont vides tant que la version n’est pas taguée, et remplies par la fonction de release au moment du tag :

  • Version — le numéro publié, en lien vers ses notes lorsqu’elles existent

  • Date — la date du tag au format AAAA-MM-JJ, triable et sans ambiguïté de locale

Une ligne dont la date est vide n’a jamais été publiée. C’est ce qui permet de retrouver le prochain nom disponible sans tenir de compteur ailleurs : c’est la première ligne sans date.
